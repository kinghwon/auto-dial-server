기기 추가

앱의 “기기 ID”와 같은 값을 입력하면 자동으로 연결됩니다
안드로이드 앱에서 서버 주소와 같은 기기 ID를 입력하고 “서비스 시작”을 누르면 하트비트가 들어옵니다. 기기를 미리 등록하지 않아도 앱이 접속하면 자동으로 목록에 나타납니다.

새 발신 스케줄

번호를 원하는 순서대로, 정해진 총 횟수만큼 예약 발신합니다
쉼표로도 구분할 수 있습니다. 최대 500개.
번호가 25개여도 총 60회로 지정하면 60건을 발신합니다. 비우거나 0이면 번호 개수만큼 1회씩.
연결 후 이 시간이 지나면 폰이 자동으로 통화를 끊습니다.
0자 · 0바이트 · SMS 1건
90바이트(한글 45자)까지 SMS 1건, 넘으면 LMS로 나뉘고 앱이 자동으로 분할 발송합니다. 최대 2000자.
비워 두면 종료일 없이 반복 실행됩니다. 이 날짜(23:59)까지만 실행합니다.
기기 지정 없이 저장하면 온라인 기기들이 하나씩 나눠서 발신합니다.
번호와 총 통화 횟수를 입력하면 발신 건수가 표시됩니다.

텔레그램 봇 설정

수신 문자를 실시간으로 받아보세요
BotFather 에서 받은 토큰. 형식: 숫자:영문/숫자
개인 대화는 본인 숫자 ID, 단체방은 -100… 형태입니다.

준비 방법

5분이면 끝납니다
  1. 텔레그램에서 @BotFather 를 검색해 대화를 시작합니다.
  2. /newbot → 이름과 사용자명을 정하면 토큰을 줍니다.
  3. 만든 봇과 대화를 열고 아무 메시지나 한 번 보냅니다.
  4. 브라우저에서 https://api.telegram.org/bot<토큰>/getUpdates 를 열어 "chat":{"id":…} 값을 확인합니다.
  5. 위 칸에 토큰과 Chat ID를 넣고 저장 → 테스트 발송을 누릅니다.
  6. 단체방으로 받으려면 봇을 방에 초대한 뒤 getUpdates 에서 -100… 로 시작하는 ID를 사용합니다.
전달이 실패하면 자동으로 3회까지 재시도하고, 실패 사유를 “수신 문자” 목록에 남깁니다.

API 키가 필요합니다

서버에 SERVER_API_KEY 가 설정되어 있습니다. 대시보드에서 사용할 키를 입력하세요. (브라우저에만 저장됩니다)
